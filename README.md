La première version de l'arbre à Histoires date de 2016. Il était constitué d'un module MPR121, d'un arduino UNO communiquant avec un PC jouant les mp3 via sa carte son.
Pour sa ré-ouverture après la période de travaux, la médiathèque de Allaire nous a demandé de réanimer ce montage.
Capteur et Arduino seront ceux utilisés à l'époque, un DFPLayer sera ajouté pour jouer les pistes MP3.
Le tout sera intégré à un boitier.
